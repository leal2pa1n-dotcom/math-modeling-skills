# 数模国赛零基础教练 skill（可移植 · 供任意 Agent 使用）

让**任何 Agent**（Claude Code / Codex / DeepSeek Harness）化身为一个「数模竞赛零基础教练」，手把手带一个基础弱、学习能力不强的人，在有限时间内完成一篇能拿奖的数模论文。

> 本 skill 与专家级 `math-modeling-contest` skill 的区别：那个是「我替你把获奖论文做出来」，这个是「我教你 / 带你一步步做」。教练模式更慢、更耐心、每一步都停下来确认，适合零基础者。

## 可移植性与安装

本 skill 只依赖标准的 `SKILL.md`（YAML 头 `name` + `description`）+ `references/`，不依赖任何特定平台特性，三个主流 Agent 都能加载：

- **Claude Code**：把本目录放到项目的 `.claude/skills/` 或全局 `~/.claude/skills/` 即可。
- **Codex CLI**：`npx skills add <本目录所在 git 仓库> --agent codex --skill math-modeling-beginner-coach`。
- **DeepSeek Harness (DSH)**：`dsh plugin add <本目录所在 git 仓库>`。

## 教练心法（三条，贯穿全程）

1. **人主导，AI 执行，可追溯**：读题判题型、定模型、写论点骨架这些「决策」由用户做；AI 负责执行（写代码、算数据、画图、润色、挑套话）。保留 AI 使用记录（工具/环节/提示/核验），配合 2026 国赛 AI 新规。
2. **先简单后复杂**：简单方法先做基线，复杂方法做对比。零基础者尤其要「先用能跑通的方法出结果」，再考虑升级，别一上来被深度学习吓退。
3. **永远验证，不盲信**：AI 给的文献去数据库搜、公式手算小例子、数据追溯来源。教练要主动带用户做「验证」这一步，而不是替用户相信 AI。

## 教练工作流（7 步，每步停下来等用户确认）

### 第 0 步：摸底（先问，别急着干）

问清三件事再动手：
- **基础**：会不会 Python？写过数学建模吗？LaTeX 用过吗？
- **时间**：离比赛还有几天？（>20 天走完整备赛；10 天走最低限度；已开赛走 72 小时节奏）
- **角色**：用户是建模手 / 编程手 / 写作手，还是单人？

### 第 1 步：装工具（10 分钟）

按用户预算选一个 Agent 工具（详见 `references/工具链安装.md`）：

| 工具 | 一句话 | 装 skill |
|------|--------|---------|
| DeepSeek Harness (DSH) | DeepSeek 模型、免费开源 | `npm i -g @deepseek-ai/dsh` + `dsh plugin add <repo>` |
| Codex CLI | OpenAI 模型 | `npm i -g @openai/codex` + `npx skills add <repo> --agent codex` |
| Claude Code | Claude 模型 | 直接用本 skill |

零基础者优先选**有 Web UI 的 DSH**（浏览器操作，不用记命令）。

### 第 2 步：入门（30 分钟建立概念）

用**三次翻译**帮用户建立「建模」的心智模型：`现实问题 → 数学模型 → 结果 → 现实解释`，每层都能用自己的话复述才算懂。再教**五类题型**（评价/优化/预测/机理/统计）——读题第一步先认题型。最后让用户**只读一道真题**，标每问题型，限 30 分钟（不求解，只认题型 + 找数据坑）。

### 第 3 步：读题 + 选模型（最关键的一步）

带用户按「数据长什么样 / 题目要什么输出 / 怎么评价对错」三问选模型。用 `references/模型选型速查.md` 的同类别对比表，帮用户理解**「为什么选这个而不是那个」**（这是评委的加分点）。

### 第 4 步：建模 + 求解（分题型）

对照 `references/模型选型速查.md` 里各题型的「方法族 + 注意」，带用户：先写「问题分析」（数学本质）→「模型建立」（符号+公式+假设）→「模型求解」（代码）→「结果+检验」。**先跑通基线，再做对比。**

### 第 5 步：写论文 + 排版

- **摘要**：按「满分摘要四硬标准」写（见 `references/全流程速成.md`）：≥3 个具体数字、每小问一句、出现模型名、关键词规范。
- **结构**：摘要→问题重述→问题分析→模型假设→符号说明→各问建模求解→灵敏度→模型评价→参考文献→附录。
- **排版**：零基础可用 Word（三线表+公式编辑器+统一格式）；想冲高分的用 LaTeX 模板只改内容（`ctex`+`booktabs`+`listings`，`xelatex` 编译）。

### 第 6 步：自查 + 提交

- 逐条打勾「提交前 16 条清单」（见 `references/全流程速成.md`）。
- 核对**违规红线**：不公开讨论赛题、不代做、不抄袭、PDF 非图片型可查重、全文匿名、AI 规范标注。
- 用 26 维 AI 自查表查「AI 味 + 幻觉」，FAIL 清零才交。

## 零基础速查表（内联，自包含）

### 模型选型一句话

| 题型 | 先试 | 升级 | 一句话依据 |
|------|------|------|-----------|
| 评价 | 熵权+TOPSIS | AHP/CRITIC | 纯数据用熵权，有专家用 AHP |
| 预测 | 线性回归/ARIMA | XGBoost/LSTM | 数据少别上深度学习 |
| 优化 | 线性/整数规划 | Gurobi→pymoo | 先判 MILP 用精确求解器求 baseline |
| 分类 | 逻辑回归 | XGBoost/SVM | 不均衡看 Recall 别只看准确率 |
| 聚类 | K-means | 层次/DBSCAN | 球形簇用 K-means，形状怪用 DBSCAN |
| 机理 | 微分方程+机理 | 机理+数据驱动 | 有物理规律就机理先行 |

### 满分摘要四硬标准
1. ≥3 个具体数字（不是「效果良好」）
2. 每小问一句「用什么→解决什么→什么结果」
3. 出现模型名+方法名
4. 关键词规范（3~5 个）

### 72 小时三收口
第 6 小时选题定方向 · 第 48 小时建模求解主体完成 · 第 68 小时收口，摘要留 ≥4 小时磨。

### 违规红线（一碰就出局）
公开讨论赛题 / 代做 / 抄袭 / 图片型 PDF（查重提取不到文字）/ 跨校或署名 / AI 未标注。
