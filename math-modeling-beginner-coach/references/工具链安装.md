# 工具链安装：Codex / DeepSeek Harness (DSH) / Skills

> 零基础者先读这段——**你不需要会写 Agent，只需要装一个工具 + 装几个现成的「技能包」**，AI 就会按固定工序帮你做数模。来源：B 站「五条数模」《十分钟学会用 Codex + DeepSeek harness + skills 拿下国赛国奖》（BV1F58H6ME6Y）。

## 一、三个工具选一个（别都装）

| 工具 | 驱动模型 | 门槛 | 适合谁 |
|------|---------|------|--------|
| **DeepSeek Harness (DSH)** | DeepSeek（可接任意 OpenAI 兼容端点） | 低（有网页界面） | 零基础、预算敏感、想要浏览器操作 |
| **Codex CLI** | OpenAI 模型 | 中（命令行） | 用 GPT 模型的人 |
| **Claude Code** | Claude 模型 | 中（命令行） | 用 Claude 的人 |

三者都支持「skills / plugins」——把一份 `SKILL.md` 指令包注入 Agent，让它按固定工序干活。**核心价值不是模型更强，而是把「获奖流程」固化成可复用的工序。**

## 二、DeepSeek Harness (DSH) 安装（推荐零基础）

DSH 是 DeepSeek AI 开源的 Agent 运行时（MIT，预览版 0.1.0-rc.6，「一切皆插件」）。

```bash
# 前置：Node.js 22.19+（建议 24 LTS）
npm install -g @deepseek-ai/dsh
dsh web            # 浏览器自动打开 http://127.0.0.1:3080
```

- 首次启动：Settings → Models 填 **DeepSeek API Key**（或其它 OpenAI 兼容端点）→ 选工作区目录。
- 四种模式：**Web UI**（新手推荐）、TUI（`dsh --profile cli`）、Headless（`dsh --profile headless "任务"`，脚本用）、Python SDK。
- 装 skill：`dsh plugin add <owner>/<repo>`。

## 三、Codex CLI 安装

```bash
npm install -g @openai/codex
codex          # 首次会要登录 OpenAI 账号 / API Key
# 装数模 skill
npx skills add sweetcornna/mathodology --agent codex --skill '*'
```

## 五、Agent 做数模的正确姿势（人主导，AI 执行）

「十分钟完成一道 C 题」≠ 全自动交卷，而是「skill 把工序排好，Agent 按序执行，人只在门控点拍板」：

1. **读题**：题目原文完整粘贴给 Agent，让它做题型分流 + 列 3 个候选方向 + 问「最容易踩的坑」，人拍板走哪条。
2. **建模**：让 Agent 给「模型名 + 完整推导 + 物理意义 + 前提假设 + 失效条件」，人核对假设是否成立。
3. **求解**：Agent 写代码 → 人核对（已知结果对一遍、极端值、量纲、可复现）→ 基线先跑、复杂方法做对比。
4. **写作**：骨架论点人写，Agent 扩写润色；摘要让 Agent 挑套话，改不改人定。
5. **验收**：交稿前跑机械自查（GateCraft `paper-gate` 或本 skill 自查清单），FAIL 清零才交。

## 六、AI 降重（有效降低 AI 重复率）

1. **别整段交给 AI 生成正文**——AI 出骨架、列数据、写代码、画图，正文用自己的话组织（最根本的一条）。
2. **改写三原则**：换句式（主动↔被动、长句拆短）、换语序（结论前置/后置）、换术语表述，而非简单同义词替换。
3. **数字与公式不靠 AI 抄**：每个数字从自己代码结果读出，公式手写/自己排版，AI 给的系数手算小例子验证（防编造）。
4. **保留可追溯记录**：按 2026 新规提交《AI 工具使用详情》（工具/版本/环节/提示过程/采纳核验），透明标注比「藏 AI 味」更安全。
5. **自查**：把成品丢给另一个大模型做「AI 味检测 + 降重建议」，逐条改完再交。

## 七、2026 国赛 AI 新规（硬约束）

- 允许用 AI，但**核心建模与分析必须参赛队主导**；用 AI 需在支撑材料交《AI 工具使用详情.pdf》。
- 未用 AI 则在参考文献后声明「本参赛队未使用任何 AI 工具」。
- 推论：工具链定位是「**人主导、AI 辅助、可追溯**」，不是无监督全自动交卷。
