# 模型选型速查（同类模型优缺点对比 + 情景选取）

> 来源：B 站「数模加油站」《数学建模比赛模型选取详细指南》（BV1Jgtt67EvN）。核心：**同一类题型下多个模型都能用，但各有前提假设与失效场景——选错模型比参数调不好更致命。**

## 选型三问（任何题先过一遍）

1. **数据长什么样**？（样本量 / 有无时间维度 / 是否删失 / 是否不平衡 / 量纲）
2. **题目要我输出什么**？（排序 / 预测值 / 最优方案 / 标签 / 分组 / 机理关系）
3. **怎么评我做得对不对**？（准确率 / 召回 / 误差 / 稳健性 / 可解释性）

→ 三者对齐才选模型；对不齐优先换模型，而非硬调参。

## 预测类

| 模型 | 适用 | 优点 | 失效场景 |
|------|------|------|---------|
| 线性/多元回归 | 线性、要解释系数 | 可解释、有检验 | 非线性/共线性/异方差 |
| ARIMA | 单变量平稳时序 | 统计完备 | 需平稳、多变量乏力 |
| 指数平滑 | 趋势+季节中短期 | 简单稳健 | 长期外推漂 |
| 灰色预测 GM(1,1) | **小样本(≥4点)**、指数型 | 样本需求极少 | 波动大/非单调时精度差；勿与灰色关联混 |
| XGBoost/LightGBM | 表格特征丰富、要精度 | 精度高、抗噪声 | 黑箱、小样本过拟合 |
| LSTM/GRU | 长序列 | 捕捉长程 | 要大量数据、难解释 |

## 评价类

| 模型 | 权重来源 | 适用 | 注意 |
|------|---------|------|------|
| AHP | 主观(专家) | 有先验、指标少 | CR<0.1，主观性强 |
| 熵权法 | 客观(离散度) | 纯数据 | 零/负值对数失效，先标准化+偏移 |
| CRITIC | 客观(波动+相关) | 指标相关性显著 | 量纲统一 |
| TOPSIS | 用上述权重 | 多方案排序 | 标准化方向绝不能搞反 |
| 灰色关联 | 无需 | 数据少、关系不确定 | 易与灰色预测混 |
| 模糊综合评价 | 隶属度 | 定性指标多 | 隶属函数主观 |

## 优化类

| 模型 | 适用 | 何时不用 |
|------|------|---------|
| 线性/整数规划 | 线性目标+约束 | 非线性/NP-hard |
| 精确求解器(Gurobi/OR-Tools) | 能建模 MILP、要全局最优 | 规模爆炸 |
| 动态规划 | 最优子结构 | 维数灾难 |
| 图论(最短路/流/生成树) | 网络/路径/指派 | 非网络结构 |
| 遗传算法 GA | 非线性、不可微、多峰 | 能精确求解却硬上 |
| DE / PSO | 连续无梯度 | 离散需改造 |
| 模拟退火 | 组合、跳局部最优 | 收敛慢 |
| NSGA-II/III | 多目标(要 Pareto) | 单目标无需 |

> **反直觉**：优化题先判类型，MILP 先用 Gurobi/OR-Tools 求精确 baseline，再上元启发式证明「能否逼近最优」，别一上来堆算法。

## 分类 / 判别类

| 模型 | 适用 | 注意 |
|------|------|------|
| 逻辑回归 | 线性、要概率+解释 | 不均衡用代价敏感+阈值 |
| SVM | 高维、小样本 | 调核+大样本慢 |
| 决策树/RF | 非线性、特征重要度 | RF 更稳 |
| XGBoost/LightGBM | 表格、要精度 | scale_pos_weight |
| 朴素贝叶斯 | 特征近似独立 | 独立性假设强 |
| KNN | 小样本、无训练 | 高维/大样本慢 |

> **不均衡铁律**：阳性少、漏判代价>误判时看 Recall/PR-AUC/MCC，别报「99.7% 准确率」。

## 聚类类

| 模型 | 适用 | 注意 |
|------|------|------|
| K-means | 球形簇、K 可估 | 归一化、肘部法定 K |
| 层次聚类 | 树状、小样本 | 选连接方式+距离 |
| DBSCAN | 任意形状、含噪声 | 调 eps/min_samples |
| GMM | 软聚类、概率归属 | 高斯假设 |
| 谱聚类 | 图/流形、非凸 | 计算量大 |

## 机理 / 统计 / 其它一句话

- **机理类**（有物理/化学规律）：微分方程 + 参数辨识，**机理先行做基线**再用数据驱动修正，别纯拟合替代机理。
- **微分 vs 差分**：连续用微分，离散用差分；**随机过程**用于随机演化；**排队论**用于服务系统；**仿真**用于难解析复杂系统。
- **空间插值**（克里金/样条/反距离）补齐空间缺失；**PCA/因子分析**降维；**相关性分析**先于回归。

## 真题选型复盘

| 真题 | 选型思路 |
|------|---------|
| 24A 板凳龙 | 几何机理→阿基米德螺旋线+递推法，不选统计/ML |
| 25C NIPT | 统计+生存+分类→LMM+KM/AFT+代价敏感逻辑回归 |
| 26C 光伏 | 机理+预测→天文几何机理基线+XGBoost 修正 |
| C038 农作物 | 优化+风险→MILP/CVaR，约束多离散故走运筹 |

> 规律：**先认「数据结构+目标」→ 定题型 → 同类里按前提假设与失效场景选最匹配的模型**，而非按「哪个听起来高级」。
