========================================================
数学建模竞赛 skill（math-modeling-contest）
安装使用说明
========================================================

【这是什么】
数学建模竞赛（CUMCM 国赛 / 五一赛 / 美赛 MCM-ICM）论文一站式产出与自查 skill。
把一道题从「原始题目 + 附件数据」变成一篇可提交、经得起 AI 痕迹自查的论文：
读题 → 6 维问题分流 → 数据预处理 → 分题型建模求解 → 论文写作 → AI 痕迹自查 → 提交合规核对 → LaTeX/PDF 产出。

【它解决什么问题】
数模竞赛最容易翻车的不是「不会建模」，而是这些隐蔽坑：
- 数据预处理漏做（重复检测、删失处理、共线性、异常值、指标方向）
- 选错模型（同类模型前提假设对不上、类别不平衡下报无意义的高准确率）
- AI 帮倒忙（编造文献/公式/数据、假设前后对不上）
- 格式不合规（正文超 30 页、图片型 PDF 无法查重、未匿名、AI 未标注）

【包含内容】
- SKILL.md —— 主工作流
- README.md —— 简介
- 安装使用说明.txt —— 本文件
- agents/openai.yaml —— Codex 接口定义
- references/ —— 10 份方法论参考

【安装方法】
本 skill 只依赖标准的 SKILL.md（YAML 头 name + description）+ references/，
三个主流 Agent 都能加载。

1）Claude Code（最简单）
   把整个 math-modeling-contest 文件夹复制到下面任一位置即可：
   - 项目内：.claude/skills/
   - 或全局：~/.claude/skills/
   目录名保持 math-modeling-contest 不变。

2）Codex CLI
   先把本文件夹上传到 GitHub 仓库，然后执行：
       npx skills add <owner>/math-modeling-contest --agent codex --skill '*' --yes
   （把 <owner> 换成你的 GitHub 用户名或组织名）

3）DeepSeek Harness (DSH)
   先把本文件夹上传到 GitHub 仓库，然后执行：
       dsh plugin add <owner>/math-modeling-contest

【使用方法】
当你要做数模竞赛题（含附件数据）、写论文、对已有论文做 AI 自查、或做备赛规划时，
让 AI 调用本 skill 即可。

核心原则（务必遵守）：
1. 人主导，AI 执行，可追溯 —— 决策你来做，AI 只执行；保留 AI 使用记录
2. 先简单后复杂 —— 简单方法先做基线，复杂方法做对比
3. 永远验证，不盲信 —— AI 给的文献/公式/数据都要独立验证
4. 获奖优先级 —— 数学结构 > 可解释 > 求解稳定 > 对比实验 > 图表 > 算法数量
