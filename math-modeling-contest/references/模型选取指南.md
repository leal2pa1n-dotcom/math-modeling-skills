# 模型选取指南（同类模型优缺点对比 + 情景选取依据）

> 来源：B 站「数模加油站」《【超清晰】数学建模比赛模型选取详细指南》（BV1Jgtt67EvN，2 集：①预测/评价/优化/图论/分类/聚类/统计 ②微分/差分/随机过程/排队/仿真/空间/插值/真题解析）。核心：**同一类题型下多个模型都能用，但各有前提假设与失效场景——选错模型比参数调不好更致命。** 与本 skill `题型与方法论.md` 互补：那里讲「每类题的完整方法链」，这里讲「同类里选哪一个 + 为什么」。

## 一、选型三问（任何题先过一遍）

1. **数据长什么样**？（样本量 / 是否有时间维度 / 是否删失 / 是否不平衡 / 指标量纲）
2. **题目要我输出什么**？（排序 / 预测值 / 最优方案 / 标签 / 分组 / 机理关系）
3. **怎么评我做得对不对**？（准确率 / 召回 / 误差 / 稳健性 / 可解释性）

→ 三者对齐才选模型；对不齐时优先换模型，而不是硬调参。

## 二、预测类：何时选哪个

| 模型 | 适用场景 | 优点 | 缺点 / 失效场景 |
|------|---------|------|----------------|
| **线性/多元回归** | 线性关系、要解释系数 | 可解释、快、有显著性检验 | 非线性/多重共线性/异方差失效 |
| **ARIMA** | 单变量平稳时序、短期外推 | 有完备统计理论 | 需平稳性、季节性要 SARIMA、多变量乏力 |
| **指数平滑(Holt-Winters)** | 有趋势+季节性的中短期预测 | 简单稳健、少参数 | 长期外推漂、无外生变量 |
| **灰色预测 GM(1,1)** | **小样本(≥4 点)**、指数型增长 | 样本需求极少 | 数据波动大/非单调时精度差；勿与「灰色关联」混淆 |
| **XGBoost/LightGBM** | 表格特征丰富、非线性、要精度 | 精度高、抗噪声、特征重要度 | 需特征工程、黑箱、小样本过拟合 |
| **LSTM/GRU** | 长序列、强时序依赖 | 捕捉长程依赖 | 要大量数据、训练慢、难解释 |
| **Prophet** | 有节假日/周期性业务时序 | 自动处理趋势+季节+假日 | 对非业务型短时序偏重 |

**真题提示**：光伏功率预测（26C）走「机理模型基线 + XGBoost 修正」而非直接 LSTM——因为数据含明确物理规律，机理先行可解释且抗泄漏。

## 三、评价类：何时选哪个

| 模型 | 权重来源 | 适用场景 | 注意 |
|------|---------|---------|------|
| **AHP 层次分析** | 主观(专家打分) | 有先验/专家意见、指标不多 | 一致性检验 CR<0.1，主观性强 |
| **熵权法** | 客观(数据离散度) | 纯数据驱动、要客观权重 | 零值/负值使对数失效，先标准化+偏移 |
| **CRITIC** | 客观(波动+相关性) | 指标间相关性显著 | 需标准差值，量纲要统一 |
| **主客观组合(乘法/加法)** | 混合 | 既要专家又要数据 | 组合方式要说明理由 |
| **TOPSIS** | 用上述权重 | 多方案优劣排序 | 标准化方向绝不能搞反(正/负向分开) |
| **灰色关联** | 无需 | 数据少、关系不确定 | 分辨率系数取值、易与灰色预测混 |
| **模糊综合评价** | 隶属度 | 定性指标多、边界模糊 | 隶属函数主观 |

**选型逻辑**：有专家先验→AHP；纯数据→熵权/CRITIC；既要客观又考虑指标相关→CRITIC 优于熵权。选题时写一句「为什么这个比另一个更适合当前场景」即是加分项。

## 四、优化类：何时选哪个

| 模型 | 适用场景 | 何时不用 |
|------|---------|---------|
| **线性/整数规划(单纯形/分支定界)** | 线性目标+线性约束、变量离散 | 非线性/大规模 NP-hard |
| **精确求解器(Gurobi/OR-Tools/CP-SAT)** | MILP/MINLP 能建模、要全局最优 | 规模爆炸时 |
| **动态规划** | 有最优子结构、多阶段决策 | 状态空间大则维数灾难 |
| **图论(最短路/最大流/最小生成树)** | 网络/路径/指派/连通 | 非网络结构 |
| **遗传算法 GA** | 非线性、不可微、多峰 | 能精确求解却硬上(降级) |
| **差分进化 DE / PSO** | 连续优化、无梯度 | 离散变量需改造 |
| **模拟退火** | 组合优化、跳出局部最优 | 收敛慢 |
| **NSGA-II/III** | 多目标(要 Pareto 前沿) | 单目标无需 |
| **博弈论** | 多方决策/对抗 | 单方决策无需 |

**反直觉升级（本 skill 核心原则）**：优化题**先判类型再选求解器**——MILP/MINLP/MIQP 先用 Gurobi/OR-Tools 求精确 baseline，再上 pymoo 元启发式证明「能否逼近最优」。别一上来就 DEGA/GA 堆算法。

## 五、分类 / 判别类：何时选哪个

| 模型 | 适用场景 | 注意 |
|------|---------|------|
| **逻辑回归** | 线性可分、要概率与可解释 | 样本不均衡用「代价敏感 + 阈值」而非只看准确率 |
| **SVM** | 高维、小样本、非线性(核) | 需调核与 C，大样本慢 |
| **决策树/RF** | 非线性、特征重要度 | 易过拟合，RF 更稳 |
| **XGBoost/LightGBM** | 表格数据、要精度 | 不均衡时用 scale_pos_weight |
| **朴素贝叶斯** | 特征独立近似成立、文本 | 独立性假设强 |
| **KNN** | 小样本、无训练 | 高维/大样本慢，要归一化 |

**不均衡铁律**：阳性少、漏判代价 > 误判时，指标看 **Recall/PR-AUC/MCC/Calibration**，别报「99.7% 准确率」（可能全预测多数类）。

## 六、聚类类：何时选哪个

| 模型 | 适用场景 | 注意 |
|------|---------|------|
| **K-means** | 球形簇、簇数已知/可估 | 需归一化，对初始点敏感，肘部法/轮廓系数定 K |
| **层次聚类** | 要树状结构、小样本 | 计算量大，要选连接方式与距离度量 |
| **DBSCAN** | 任意形状、含噪声 | 需调 eps/min_samples，密度不均失效 |
| **高斯混合 GMM** | 软聚类、要概率归属 | 假设高斯分布，EM 可能局部最优 |
| **谱聚类** | 图/流形结构、非凸 | 计算量较大 |

## 七、统计 / 机理 / 其它：一句话选型

- **机理类（有物理/化学规律）**：微分方程建模 + 参数辨识，**机理先行做基线**，再用数据驱动修正（26C 光伏范式）。别用纯拟合替代机理。
- **微分方程 vs 差分方程**：连续变化用微分，离散时间用差分；**随机过程（马尔可夫链/泊松/布朗）**用于有随机性的演化；**排队论**用于服务系统；**仿真（蒙特卡洛/离散事件）**用于难解析的复杂系统。
- **空间类**：插值（克里金/样条/反距离）用于补齐空间缺失；**主成分/因子分析**用于降维；**相关性分析**先于回归，别跳过 EDA 直接上模型。

## 八、真题选型一句话复盘

| 真题 | 选型思路 |
|------|---------|
| 24A 板凳龙 | 几何机理题→阿基米德螺旋线参数方程 + 递推法，不选统计/ML |
| 25C NIPT | 统计+生存+分类→LMM+KM/AFT+代价敏感逻辑回归，数据含删失故走生存 |
| 26C 光伏 | 机理+预测→天文几何机理基线 + XGBoost 修正，数据含物理规律 |
| C038 农作物 | 优化+风险→MILP/CVaR，约束多且离散故走运筹而非纯 GA |

> 规律：**先认「这题的数据结构与目标」→ 定题型 → 同题型里按前提假设与失效场景选最匹配的模型**，而非按「哪个模型听起来高级」。
