# 失败案例库（反例：哪里错 / 为什么 / 如何发现 / 如何修复）

> 比多收 100 篇 O 奖论文更重要的是「能识别哪一步不严谨、哪个假设勉强成立、哪个模型只是竞赛写法」。每个反例固定四段：**场景 → 哪里错 → 如何发现 → 如何修复**。
> 配套速查表见 `竞赛推理与决策.md` §八（18 条反射清单）；本文是逐条的详细展开。

## 1. 小样本上高维深度学习

- **场景**：20 个样本、50 个特征，上 XGBoost/深度网络，训练精度 99%
- **哪里错**：过拟合，泛化差
- **如何发现**：交叉验证/留出集测试精度暴跌；特征数 > 样本数
- **如何修复**：降维（PCA/Lasso）、换简单模型、增样本、正则

## 2. 时间序列随机切分（数据泄漏）

- **场景**：`train_test_split(..., shuffle=True)` 切时序
- **哪里错**：训练集含未来信息
- **如何发现**：测试集异常地好；检查切分方式
- **如何修复**：按时间顺序切分（前 80% 训练 / 后 20% 测试）

## 3. 相关当因果

- **场景**：Pearson r=0.92 → 「A 导致 B」
- **哪里错**：相关 ≠ 因果，有混淆变量
- **如何发现**：有无第三变量共同驱动
- **如何修复**：只写「相关」；因果需实验/工具变量/因果图

## 4. 优化解违反约束

- **场景**：程序找到「最优解」但不满足约束
- **哪里错**：约束建模遗漏 / 罚项权重不当
- **如何发现**：逐约束代入验证
- **如何修复**：补约束 / 加罚项 / 换可行解

## 5. 幻觉引用

- **场景**：「据某机构 2025 数据显示……」网页根本不存在
- **哪里错**：编造来源/数据
- **如何发现**：逐条检索核验
- **如何修复**：换可查证来源或删，标「未验证」

## 6. 严重共线性

- **场景**：BMI 与身高体重同时进回归，VIF>10
- **哪里错**：结构性共线使系数不稳
- **如何发现**：VIF / 相关矩阵
- **如何修复**：删定义相关变量 / 岭回归

## 7. 异常值未处理

- **场景**：均值被极端值带偏
- **如何发现**：箱线图 / 分布
- **如何修复**：先看分布再定（截尾/变换/鲁棒回归）

## 8. 量纲 / 单位错误

- **场景**：亿元与万元混用
- **如何发现**：数量级核对
- **如何修复**：统一单位

## 9. 归一化方向错

- **场景**：按行（样本）归一化而非按列（特征）
- **如何发现**：检查 axis
- **如何修复**：按特征列归一

## 10. 指标方向搞反

- **场景**：正向/负向指标标准化方向错
- **如何发现**：核对题目定义
- **如何修复**：正向化分开处理

## 11. 模型假设不成立

- **场景**：非正态数据上参数检验
- **如何发现**：前提检验（正态/方差齐）
- **如何修复**：换非参 / 变换

## 12. 参数异常

- **场景**：负概率、负时间
- **如何发现**：范围检查
- **如何修复**：加约束 / 换分布

## 13. 评价指标方向错

- **场景**：把「越小越好」当「越大越好」排序
- **如何发现**：核对目标语义
- **如何修复**：反向处理

## 14. 缺失处理错误

- **场景**：直接删 / 均值填
- **如何发现**：缺失机制（MCAR/MAR/MNAR）
- **如何修复**：按机制插补 / 多重插补

## 15. 论文—代码不一致

- **场景**：论文公式/参数/结果与代码对不上
- **如何发现**：逐项比对复现
- **如何修复**：修正到可复现，不得为漂亮结果改事实

## 16. 组合模型无必要

- **场景**：简单基线已足够却堆组合
- **如何发现**：对比 baseline
- **如何修复**：砍掉过度建模

## 17. 单位/量纲导致数量级离谱

- **场景**：结果比常识大几个数量级
- **如何发现**：与已知量级比对（人口不可能几十亿、GDP 不可能负）
- **如何修复**：回查单位换算

## 18. 引用不存在 / 虚构数据

- **场景**：论文/参数/网页查无实据
- **如何发现**：每条去数据库/官网搜
- **如何修复**：删除或替换为可核验来源，标「未验证」
