# 语料来源（真实可核验下载源，供「按清单自动搜集」用）

> 只记录**已核验存在**的源；未验证的一律不写。搜集时优先官方来源、原始论文、原始数据。数据/参数类事实一律走「推导 vs 查询分离」，查不到的标「未验证」。

## 美赛 MCM / ICM

- **Running-Turtle1/MCM-ICM**（GitHub）：2004–2025 美赛 O 奖论文合集，含 2020–2025 各年特等奖（Outstanding）文件夹。
  - 已知缺口：2017 / 2020 / 2023 缺题面；2024 仅 A 题 O 奖。
  - 地址：https://github.com/Running-Turtle1/MCM-ICM
- **COMAP 官网**（赛题与规则官方源）：https://www.contest.comap.com/undergraduate/contests/

## 国赛 CUMCM

- **yushugulao/CUMCM-Archive**（GitHub，推荐首选）：1992–2025，5244 个文件，`manifest.csv` 索引 + PDF 文本镜像；目录 `竞赛资料/<年份>/<题号>/赛题/` 与 `/优秀论文/`。
  - 地址：https://github.com/yushugulao/CUMCM-Archive
- **官网**：cumcm.cnki.net（赛题公示）、mcm.edu.cn
- **数学中国（madio.net）论坛**：92–09 年论文/点评合集；92–20 年赛题+论文打包（回帖获取）。
- **shumo.com wiki**：按年份的 CUMCM 优秀论文（含获奖作者/单位）。

## 搜集铁律（沿用 skill 停止规则）

- 论文 PDF 损坏 / 图片型无法 OCR / 来源不明 / 结果明显错误 → 降级或剔除。
- 宁可 1000 篇高质量，不要 10000 篇垃圾 PDF。
- 每篇高质量论文提取「解题过程」而非只记「最终模型」：子问题 → 变量 → 目标/约束 → 候选模型 → 选模理由 → 数据/清洗 → 参数 → 求解 → 验证 → 敏感性 → 局限。
