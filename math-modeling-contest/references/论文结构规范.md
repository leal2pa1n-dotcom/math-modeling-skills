# 论文结构规范（蒸馏自获奖论文）

## 标准章节结构

```
标题（含建模方法关键词）
摘要 + 关键词
一、问题重述
二、问题分析
三、模型假设
四、符号说明
五~八、各问「模型建立与求解」（每问一章）
九、灵敏度分析
十、模型评价与推广
参考文献
附录（代码）
```

## 各章写作要点

### 摘要（评委第一眼，决定档次）
- 一页内概括：**用什么模型 → 解决什么问题 → 什么结果**
- 每个问题一句「针对问题X，本文……建立……模型，结果表明……」
- 放关键数字（如「ICC=0.73」「召回率0.977」「nRMSE=0.0150」）
- 结尾一句「综上，本文形成……完整流程，可为……提供量化依据，但……仍需……」（诚实说明局限）

### 问题分析
- 写清每个问题的**数学本质**（"问题二的数学本质是把……转化为……"）
- 说明问题间的递进关系（多问之间的逻辑链条）

### 模型假设
- 明确、可检验，编号列出（如「假设光伏出力不受电网调度限制」「假设降尺度误差空间平稳」）

### 符号说明
- 表格：符号 | 含义 | 单位 | 类型（观测值/计算值/常数/中间变量/评价指标）

### 模型建立与求解（每问四段式）
1. **问题分析**：数学本质
2. **模型建立**：变量定义 → 公式 → 推导 → 前提假设
3. **模型求解**：算法步骤、代码要点、参数
4. **结果与检验**：结果表/图 + 合理性检验 + 与基线对比

### 灵敏度/稳健性分析
- 关键参数扰动（如检测误差、折扣率、代价比）→ 结果变化 → 结论是否稳健
- 展示模型「经得起扰动」，是获奖论文与普通论文的关键分水岭

### 模型评价
- **优势**（3 条为宜）：完整性 / 可解释性 / 场景适应性
- **不足与改进**：诚实说明局限（如「女胎阳性判定仍需结合临床诊断」）

## 写作红线

- 公式前后必须有文字说明，不孤立出现
- 图表要有编号和标题，坐标轴标签清晰
- 不得编造数据/文献/结论（AI 写作尤其要防）
- 避免「不是……而是……」滥用、空泛表述；结论要落在具体机制/数字上

## 提交前 16 条清单（交稿前逐条打勾，可操作）

> 来自云顶数模 20 天计划（原文给写作手以外的人打勾用）。建议换一个人或隔一小时勾。

1. 摘要里有模型名、方法名，至少三个具体数字
2. 题目每一小问，正文都有对应小节和结论
3. 每条假设后面有依据，没有「忽略一切因素」
4. 符号表覆盖反复出现的符号，带着单位
5. 公式已编号，正文用编号引用
6. 图有图号图题（图下方），坐标轴中文标签带单位
7. 表是三线表，表题在上方，小数位统一
8. 每张图表正文都引用并解释了，不是孤零零贴着
9. 求解部分写了算法、工具、参数、大概跑了多久
10. 至少两个参数做了灵敏度，并有一句结论（变不变、在哪切换）
11. 有单独的模型检验，没和灵敏度写成一锅
12. 缺点是真的，并写了以后怎么改
13. 参考文献格式统一，正文对得上编号
14. 附录代码有注释和小标题，没有把全部打印输出倒进去
15. 错别字、术语、单位前后一致
16. 页码目录页眉正常，PDF 能打开

## 排版工程化

- LaTeX：`ctex`（fandol 字体）+ `amsmath` + `booktabs`（三线表）+ `listings`（代码）+ `tikz`/`matplotlib`（矢量图）
- 编译链：`xelatex`（中文）；VSCode LaTeX Workshop 一键编译
- 交付链：`.md` 草稿 → `.tex` → `.pdf` → `.docx`
