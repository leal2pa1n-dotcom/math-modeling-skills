# 备赛冲刺与时间管理（20 天 / 最低 10 天）

> 来源：云顶数模「零基础 20 天用 AI 拿下国赛冲奖计划表」。本文件是可执行浓缩版，供「距开赛还有 N 天」时快速排计划。

## 一、备赛心法

- **三次翻译**：现实问题 → 数学模型 → 结果 → 现实解释。建模就是把实际问题逐层翻译，每层都能用自己话复述才算懂。
- **五类题型**：评价 / 优化 / 预测 / 机理 / 统计——读题第一步先认题型，评价题就评价、优化题就写规划、机理题别只拟合一条曲线。对应本 skill 的 6 维分流（见 `SKILL.md` 第 0 步）。
- **先懂题再补 Python**：把「读题 → 清洗 → 出结论」链路走通，再补工具，少做无用功。
- **光看完不算数**：代码跑通 / 练习题写在纸上才叫过，没做完留格子第二天补半栏，别推倒重来。

## 二、20 天冲刺节奏

每天 2.5~3 小时（周末 4 小时）。主线 4 份资料：导论、数据预处理、论文写作、AI 辅助建模。

| 阶段 | 天数 | 干什么 |
|------|------|--------|
| 把路走通 | 第 1-5 天 | 三次翻译/五类题型 → 假设怎么写 → 评审表/72 小时 → 缺失三机制 → 异常值/EDA |
| 模型上手 | 第 6-13 天 | Pandas 流水线脚本 → 评价(AHP/熵权/TOPSIS) → 优化(pulp) → 图论(networkx) → 回归 → 时间序列 → 灰色/蒙特卡洛 → 补欠账 |
| 能写出来 | 第 14-17 天 | 摘要模板/正反例 → 16 条清单 → 三人分工 → 六条提示词 |
| 合练 | 第 18-20 天 | 3 小时独立定题 → 最小闭环(清洗+模型+图) → 一页摘要 + 弱点清单 |

关键动作（每阶段必做）：
- 第 1 天：找一届真题**只读题**，标每问题型，限 30 分钟。
- 第 3 天：按「模型名 + 数字 + 对比 + 建议」四要素写 ≤300 字摘要草稿。
- 第 6 天：把预处理收成一个可复用函数，**训练集 fit 缩放、测试集只 transform**。
- 第 7 天：手算 AHP（含 CI/CR）+ 熵权/TOPSIS 对比，写「谁更合理」。
- 第 15/20 天：用「提交前 16 条清单」（见 `论文结构规范.md`）逐条打勾。
- 第 20 天：写一页摘要 + 列「20 天还不会的」3 条弱点，赛后按需回补。

## 三、最低限度 10 天（被打断也能上场）

**第 1、2、3、4、5、7、8、14、16、20 天**。评价 + 优化 + 会写摘要，覆盖不少 B/C 题；图论/回归/时间序列/AI 提示词属于拉差距项，有空再补。

## 四、三人分工与 72 小时节奏

- **建模手**拍板模型，**编程手**对数字负责，**写作手**从第一小时搭架子（不是最后一天才上场）。三个人都要读题——评委只看论文。
- 72 小时三条线：**第 6 小时**（选题/定方向）、**第 48 小时**、**第 68 小时**（收口）。摘要页几乎决定初评，留 4 小时以上打磨。

## 五、资料包态度（别什么都学）

| 态度 | 系列 | 说明 |
|------|------|------|
| 20 天主吃 | 01 数学建模基础、02 预测统计、09 论文写作 | B/C 题大半在 01；C 题和带表题围着 02 |
| 用到再翻 | 03 算法优化、04 Python 可视化、16 算法图鉴 | 规模太大写不进求解器时再来；04-04 绘图单独留一晚 |
| 备用 | 05 机器学习 | 别一上来就上，先问这题是不是真该用 ML |
| 先别排 | 06 深度学习、07 CV、08 NLP、11/12/13 进阶 | 常规数模很少刚需 |

> AI 使用红线（文献/代码/写作/假设/分工）与六条提示词见 `AI辅助与自查.md`。
