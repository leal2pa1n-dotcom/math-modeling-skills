# 案例库（已解析的真实获奖论文）

> 每个案例标注了「题型 → 方法链 → 可借鉴点」，供解题时对照参考。

## 案例 1：25 年国赛 C 题 NIPT 检测时点优化（国二）

- **题型**：生存/删失 + 分类
- **方法链**：线性混合效应模型（问题一）→ Kaplan-Meier 生存分析 + 回归树 BMI 分组（问题二）→ 加速失效时间模型 AFT（问题三）→ 代价敏感逻辑回归（问题四）
- **可借鉴点**：
  - 重复检测 → 孕妇级数据聚合（ICC=0.73 说明个体差异是主波动源）
  - 删失三情形处理（左删失/区间插值/右删失）
  - VIF 共线性诊断剔除结构性共线变量（BMI/身高/体重 VIF 高达 233/104/367）
  - 不均衡分类用代价敏感 + 召回率（漏判:误判=10:1，召回 0.977 vs 基线 0.159）
- **来源**：2025 国赛 C 题 NIPT 国二获奖论文复盘

## 案例 2：26 年 C 题 光伏电站功率预测

- **题型**：预测 + 机理
- **方法链**：天文几何机理模型（问题一）→ XGBoost 历史功率预测（问题二）→ NWP 融合（问题三）→ NWP 空间降尺度（问题四）
- **可借鉴点**：
  - 特征工程三件套（滞后/滚动统计/时间编码），nRMSE 达 0.0150
  - 机理模型做基线 + 数据驱动修正
  - 场景划分（晴空指数）做针对性分析，降尺度在云天改善最大（3.8%）
- **来源**：2026 国赛 C 题光伏功率预测获奖论文复盘

## 案例 3：C038 农作物种植规划优化

- **题型**：优化 + 风险
- **方法链**：多约束利润最大化模型 → DEGA（差分进化+遗传改进）智能算法求解 → CVaR 风险建模 → 敏感性分析
- **可借鉴点**：
  - 复杂约束建模（地块类型/轮作/连续种植/销量上下限，达 12 类约束）
  - 不确定性用 CVaR（条件风险价值）纳入目标，比只优化期望稳健
  - 确定性 vs 风险模型对比，展示 CVaR 模型收益更高且风险可控
- **来源**：C038 农作物种植规划优化获奖论文

## 案例 4：C132 NIPT 检测决策优化（统计建模 + 元学习，高阶路线）

- **题型**：生存/删失 + 分类（与案例 1 同题，但方法更进阶）
- **方法链**：
  - 问题一：改进线性混合效应模型（LMM）+ 限制性最大似然（REML），ICC=74.3%，AIC 比传统回归提升 17.2%
  - 问题二：改良高斯过程回归（GPR）+ 三阶段分层决策 + 遗传算法（GA）全局优化 BMI 分组与检测时点
  - 问题三：**混合深度生存网络**（MLP 处理静态特征 + LSTM 处理时序特征 + DeepHit 生存分析头），预测精度 94.7%
  - 问题四：**LightGBM + Optuna 堆叠集成**（元特征 + 堆叠元模型），女胎异常二分类准确率 99.7%
- **可借鉴点**：
  - 同题「传统统计（国二）」vs「深度学习+元学习（国一）」的方法光谱，选题时可据此决定复杂度
  - 深度生存网络处理「多维异构特征」（静态 + 时序）的范式
  - Optuna 自动调参 + 堆叠集成处理不均衡小样本
- **来源**：C132 NIPT 检测决策优化获奖论文

## 案例 5：2024 国赛 A 题 板凳龙（几何/运动学，阿基米德螺旋线 + 递推法）

- **题型**：机理/几何/运动学
- **方法链**：极坐标建模（阿基米德螺旋线）→ 龙头速度-极角关系 → 龙身/龙尾递推法 → 结果表 + 运动状态示意图
- **可借鉴点**：
  - 「头带动身」的几何题：先定坐标系与参数方程，再由连接约束**递推**出全身位置/速度
  - 问题分析用**框图**展示求解链（螺线方程 → 龙头位置 → 极角-时间关系 → 龙身/龙尾位置 → 各位置速度 → 递推法），一眼看清思路
  - 结果双呈现：坐标结果表（分时刻分节 x/y）+ 运动状态示意图（如 t=300s 末态图）；结果表标注「全部结果见附件 result1.xlsx」控制正文篇幅
- **来源**：B 站直播 A 优秀论文截图（武汉大学示例）

## 案例对比：同题不同档次的启示

| | 案例 1（国二） | 案例 4（高阶） |
|---|---|---|
| 问题二 | KM 生存分析 + 回归树分组 | GPR + 三阶段分层 + GA 全局优化 |
| 问题三 | 对数正态 AFT | MLP+LSTM+DeepHit 混合深度生存网络 |
| 问题四 | 代价敏感逻辑回归（召回 0.977） | LightGBM+Optuna 堆叠（准确率 99.7%） |
| 共性 | 都做「重复检测→孕妇级聚合 + 删失处理 + 时点优化」 | 同左 |
| 启示 | 数据结构处理是地基；方法复杂度是上限，但不是决定胜负的唯一因素 | 同左 |

> 核心结论：**国二与国一的地基（数据预处理、删失处理、问题拆解）完全一致，区别在方法上限。先把地基打牢，再决定是否上深度学习。**
