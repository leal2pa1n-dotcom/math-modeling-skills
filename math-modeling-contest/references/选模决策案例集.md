# 选模决策案例集（同题异解 + 选模理由）

> 核心训练材料：不是「这题用了什么模型」，而是「为什么选它、为什么不选另一个」。本文给一批真实赛题的**同题异解对照**，让 Agent 学会「不同模型都能做，但哪个更合适」。
> 与 `模型选取指南.md`（同类模型优缺点表）互补：那里是「字典」，这里是「在真实题上的决策过程」。

## 读法

每个案例固定结构：**题目 → 数据结构画像 → 候选方案（2~4 个）→ 各候选适用/优缺点 → 最终选择 + 理由 → 什么情况下改选**。

## 案例 1：人口预测（CUMCM 2007 A）

- **题目**：预测某地区未来人口
- **数据结构画像**：年度人口总量，样本少（十几~几十点），有趋势，可能受出生/死亡/迁移驱动
- **候选**：
  - 灰色 GM(1,1)：样本少、指数增长 → 需求极少、快；数据波动大/有结构变化时失真
  - ARIMA：单变量时序、短期外推 → 有统计理论；需平稳、多变量乏力
  - Logistic/阻滞增长：人口有环境容量上限 → 机理清晰；需设容量 K
  - cohort-component（队列要素法）：出生/死亡/迁移驱动 → 最可信；需分龄分性数据
- **最终**：数据少且只看总量 → GM(1,1)/Logistic 做基线；若有分龄数据 → cohort-component 更可信
- **改选条件**：有分龄/分性/迁移数据 → 上队列模型；数据波动大 → 别用灰色

## 案例 2：传染病传播（CUMCM 2003 A SARS）

- **题目**：SARS 传播规律与预测
- **候选**：SIR/SEIR（机理 ODE）、元胞自动机（空间离散）、Agent-based（个体异质）、纯统计拟合
- **最终**：SEIR（含潜伏期）做主模型，参数用数据拟合；要空间/个体差异再上元胞/Agent
- **关键判断**：有明确传播机制 → **机理 ODE 先行**，别用纯统计外推

## 案例 3：葡萄酒评价（CUMCM 2012 A）

- **题目**：两组品酒员评价结果可信度 + 葡萄酒分级
- **候选**：AHP（主观）、熵权法（客观）、CRITIC（波动+相关）、TOPSIS（排序）、灰色关联
- **最终**：显著性检验比较两组评价 → 主客观组合权重 + TOPSIS 排序
- **改选条件**：有专家先验 → AHP；纯数据 → 熵权/CRITIC；指标相关显著 → CRITIC 优于熵权

## 案例 4：脑卒中发病因素（CUMCM 2012 C）

- **题目**：分析脑卒中发病影响因素并预测
- **候选**：Logistic（可解释、给概率）、SVM（高维）、决策树/RF（非线性+重要度）、XGBoost（精度）
- **最终**：Logistic 做可解释主模型 + RF/XGBoost 做精度对比；因素重要性用系数/特征重要度
- **关键判断**：要「哪些因素 + 影响方向」→ **Logistic 可解释优先**，别只上黑箱

## 案例 5：农作物种植优化（C038）

- **题目**：多地块多年种植规划，利润最大 + 风险
- **候选**：线性/整数规划（MILP）、GA、SA、CVaR 风险模型
- **最终**：MILP 精确求解做 baseline + CVaR 纳入风险 + DEGA 证明逼近最优
- **反直觉**：约束多且离散 → **运筹精确求解器先行**，别一上来 GA 堆算法

## 案例 6：光伏功率预测（26C）

- **题目**：预测光伏输出功率
- **候选**：机理模型（天文几何）、XGBoost、LSTM、ARIMA
- **最终**：机理基线 + XGBoost 修正；数据含物理规律 → 机理先行抗泄漏、可解释
- **改选条件**：无物理规律、纯时序 → 才考虑 ARIMA/LSTM

## 通用选模模板（写作可直接套）

```
本文备选模型：A / B / C
A：+优点；−缺点（适用条件 / 数据要求 / 可解释性）
B：+...；−...
C：+...；−...
结合本文 [数据结构 / 目标 / 评价逻辑]，选择 [X]，理由：...
```

> 规律（来自 `模型选取指南.md`）：先认「这题的数据结构与目标」→ 定题型 → 同题型里按前提假设与失效场景选最匹配的模型，而非按「哪个模型听起来高级」。
