# 顶刊图表美化提示词（Nature / Science 级视觉规范）

> 来源：2026 国赛《超精美图表 AI 自动优化升级提示词》v3.0（SCI-Enhanced Edition）。
> 用途：把一张粗糙的 matplotlib/R/Origin 图，通过「AI 一键美化」或「手动参数对照」提升到 Nature/Science/Lancet/Cell 出版级。
> 核心承诺：**美化不修改 · 提质不增项 · 规范不复杂**，另加 v3.0「智能补图」。

---

## 0. 五项不可逾越的硬性规则（AI 美化底线）

| # | 规则 | 含义 |
|---|------|------|
| ① | 数据保真 | 每个数据点、数值、标签、坐标刻度必须与原图完全一致。原图有错只能标注提示，**不能擅自修改** |
| ② | 类型保留 | 柱状图必须保留柱状图、热力图保留热力图，**不得转换图表类型**（柱改饼、折改柱等） |
| ③ | 结论保留 | 原图呈现的统计结论、显著性、趋势、聚类必须完全可见可读 |
| ④ | 比例保真 | 柱高、扇区、坐标轴比例、颜色映射必须与原数据成比例 |
| ⑤ | 标注完整 | 注释、图例、单位、来源、显著性符号（\*、\*\*、\*\*\*、ns）必须全部保留并提升可读性 |

**AI 输出格式**（完成美化后按此结构化输出）：

```
【图表类型识别】: [热力图/柱状图/折线图/...]
【原图问题诊断】: [2-4 个具体视觉缺陷]
【美化执行清单】: [颜色/字体/网格/边距/标记/标注 各项修改]
【数据完整性检查】: [确认所有数据点/标签已保留]
【生成结果】: [300 DPI PNG 或 SVG]
【修改说明】: [逐项解释每处修改的作用与依据]
```

## 1. 核心设计原则（10 条黄金法则）

法则 1–5 为**硬约束**（必须遵守），6–10 为**软约束**（推荐遵守，违反须在说明中解释原因）。

| 法则 | 原则 | 要点 |
|------|------|------|
| 1 | 数据至上 (Data First) | 数据是主角，颜色/网格/边框是配角。深色数据点 + 浅色背景 |
| 2 | 少即是多 (Less is More) | 去除顶/右边框、冗余网格、高饱和背景。留白 = 专业感 |
| 3 | 色彩克制 (Color Restraint) | 全图 ≤ 3–5 种主色；优先色盲友好（viridis/plasma/RdBu）；避免红绿搭配 |
| 4 | 对比鲜明 (High Contrast) | 数据与背景明度差 ≥ 7:1（WCAG AAA）；轴线用深灰 #333 而非纯黑 |
| 5 | 字体一致 (Font Consistency) | 全图 1–2 种字体；中文思源黑体/微软雅黑，英文 Arial/Helvetica；字号梯度 ≤ 3 级 |
| 6 | 对齐精确 | 多子图横纵坐标、colorbar、图例位置一致；图例框 ≤ 图的 25% |
| 7 | 标注清晰 | 优先级：主标题 > 副标题 > 轴标签 > 刻度 > 数据标签 > 脚注；字号按 2:1.5:1.2:1:0.85 缩放 |
| 8 | 比例正确 | 单图 4:3 或 3:2；多子图 16:9 或 2:1；热力图正方形 1:1 |
| 9 | 可访问性 | 色盲友好、打印友好（灰度可区分）、屏幕阅读器 alt 文本 |
| 10 | 可复现性 | 提供完整绘图代码或参数，读者 100% 复现 |

## 3. 字体与排版规范

### 3.1 字体字号（字号梯度）

| 元素 | 字号 | 字重 | 字体 | 颜色 |
|------|------|------|------|------|
| 主标题 | 14–16 pt | Bold | Arial / 思源黑体 | #000000 |
| 副标题 | 11–12 pt | Regular | Arial / 思源黑体 | #333333 |
| 轴标签 (x/y) | 10–11 pt | Regular | Arial | #333333 |
| 刻度标签 | 9–10 pt | Regular | Arial | #555555 |
| 图例 | 9–10 pt | Regular | Arial | #333333 |
| 数据标签 | 8–9 pt | Regular | Arial | #222222 |
| 脚注/来源 | 8 pt | Italic | Arial | #666666 |
| 公式 (LaTeX) | 10 pt | Italic | Cambria Math / Times | #000000 |

### 3.2 网格与边框

- **去除**：默认去除上边框和右边框 (spine)。
- **保留**：左/下边框用淡灰 #999999 + 0.5–1.0 pt 线宽。
- **网格**：仅主网格线 (major grid)，颜色 #E0E0E0，虚线/点线，alpha=0.4–0.6。
- **刻度**：方向统一（in 或 out）。
- **背景**：主图区纯白 #FFFFFF，图外背景 #F5F5F5 浅灰（可选）。

**matplotlib 参考代码：**

```python
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)
ax.spines['left'].set_color('#333333')
ax.spines['bottom'].set_color('#333333')
ax.grid(True, axis='y', linestyle='--', linewidth=0.5, color='#CCCCCC', alpha=0.5)
ax.set_axisbelow(True)   # 网格在数据下方
```

## 4. 图表 8 大元素规范

### 4.1 Title（标题）
- 主标题：粗体 14–16 pt，顶部居中；副标题：常规 11–12 pt。
- 内容必须含：研究对象 + 关键变量 + 区域/时间 + 方法（如 `Spatiotemporal Dynamics of NDVI in Yangtze River Basin (2000-2020)`）。
- 避免 `Figure 1`、`Results` 等无信息量标题。

### 4.2 Axis（坐标轴）
- 轴标签必须含单位（`Temperature (°C)` 而非 `Temperature`）。
- 每轴 4–8 个主刻度；log scale 时注明，可加 minor ticks。

### 4.3 Legend（图例）
- 位置：右上 / 底部 / 图外；无边框或淡灰边框；半透明白底 alpha=0.85。
- 顺序与数据系列一致；图例框 ≤ 图区 25%。

### 4.4 Grid（网格）
- 主网格线足够；minor grid 仅精细数据用。
- `linestyle='--'` 或 `':'`，`color='#CCCCCC'`，`alpha=0.4-0.6`，`linewidth=0.5`。

### 4.5 Marker（数据标记）
- 系列数 → 标记/线型组合：

| 系列数 | 标记组合 | 线型 |
|-------|---------|------|
| 1 | ● | 实线 - |
| 2 | ● ■ | 实线 / 虚线 -- |
| 3 | ● ■ ▲ | 实线 / 虚线 / 点线 : |
| 4 | ● ■ ▲ ▼ | 4 种线型 |
| ≥5 | 标记+线型+颜色 | 色板区分为主 |

### 4.6 Error Bar（误差棒）
- `capsize=4-6`，`elinewidth=1.2-1.5`，`capthick=1.2-1.5`。
- 颜色与数据系列同色但稍浅 (alpha=0.6)。
- 类型要明确：SD（描述）/ SEM（推断）/ 95% CI（效应量）/ IQR（箱线图）。

### 4.7 Annotation（注释）
- 文本框：`facecolor='white'`、`edgecolor='#999'`、`alpha=0.9`、`boxstyle='round,pad=0.3'`。
- 箭头：`FancyArrowPatch`，`arrowstyle='->'`，`color='#333333'`，`linewidth=1.0`。
- 内容 ≤ 8 词。

### 4.8 Colorbar（颜色条）
- 位置右侧/底部；高度 = 主图 60–80%；标签含单位 9–10 pt。
- 3–7 个主刻度；分类图用 BoundaryNorm + 离散 colorbar。

## 5. 12+ 类图表分项美化规范

### 5.1 柱状图与条形图
- **配色**：单系列统一主色（#1F3A93）；≤4 系列用 Set1/Dark2；重点柱主色 + 其余浅灰 #CCCCCC；正蓝 #1976D2 / 负红 #D32F2F。
- **几何**：柱宽 = 类别间距 60–80%；`edgecolor='#333333'` linewidth 0.5–1.0；类别按数值降序（排名图）。
- **标注**：柱顶上方数值标签 8–9 pt；误差棒含 SD/SEM/95%CI；显著性 \* \*\* \*\*\* + 横线 bracket。
- **常见错误**：Y 轴不从 0 开始（除非标注 broken axis）、3D 柱图、双 Y 轴混乱、柱子过密。

### 5.2 折线图与面积图
- **配色**：主色 #1F3A93 线宽 2.0；多系列独立色 + 线型区分；原值实线 / 拟合虚线 / 置信带半透明填充。
- **几何**：主线 1.5–2.0 pt；数据点 ≤50 全标记，>50 仅关键点；阶梯图 `drawstyle='steps-post'`。
- **标注**：关键点注释框 + 箭头；95% CI 用同色 alpha=0.15–0.25 填充；回归方程 + R² 用 LaTeX。
- **常见错误**：>5 条线混乱、缺失数据不标记、双 Y 轴比例不当。

### 5.3 散点图与气泡图
- **配色**：单变量散点单色 + alpha 0.6–0.8；分类散点每类独立色；连续映射 viridis/plasma + colorbar；气泡大小映射第三变量 (size 20–2000, alpha 0.5–0.7)。
- **几何**：`s=20-100`；标记形状 ● ■ ▲ ◆ ✕ 区分；`edgecolors='#333'` linewidth 0.3–0.5；点数 >500 用 hexbin / 2D hist / KDE。
- **标注**：OLS 拟合虚线 + 95% CI 带 + 公式/R²/p；聚类用半透明 ellipse；异常点红边 + 标签。
- **常见错误**：气泡重叠无透明度、大小未标准化、三维散点无可读视角。

### 5.4 热力图与相关性矩阵
- **配色**：双向（相关系数）RdBu_r / coolwarm `vmin=-1, vmax=+1, center=0`；单向 viridis/plasma/inferno；显著性 \* \*\* \*\*\* 叠加。
- **几何**：正方形 cell `aspect='equal'`；`seaborn.clustermap` 加 dendrogram；相关性矩阵 mask 隐藏上/下三角。
- **标注**：单元格数值 7–9 pt；colorbar 必备；分组边框 Rectangle。
- **常见错误**：colorbar 范围不匹配、双向数据用 RdYlGn、行列标签过长未旋转。

```python
import seaborn as sns
sns.heatmap(corr, annot=True, fmt='.2f', cmap='RdBu_r', center=0,
            vmin=-1, vmax=1, square=True, linewidths=0.5,
            cbar_kws={'label': 'Correlation'})
```

### 5.5 箱线图 / 小提琴图 / 分布图
- **配色**：箱体 #1F3A93 alpha=0.5–0.7 描边 #000；多组独立色 `patch_artist=True`；小提琴 viridis 渐变；散点叠加 stripplot/swarmplot alpha=0.4。
- **几何**：`widths=0.5-0.7`；中位线 #000 linewidth 2.0；均值红菱形 ◆；`notch=True` 显示 95% CI。
- **标注**：Outlier `fliersize=4`；t-test/Mann-Whitney/ANOVA + p 值横线；样本量 n=XX。
- **常见错误**：未标注样本量与统计方法、Y 轴截断、Outlier 误判（应 1.5×IQR）。

### 5.6 饼图 / 环形图 / 旭日图
- **配色**：Set2 / Pastel1 / tab10；关键扇区主色 + `explode=0.05`；环形 `width=0.3-0.4` 中心放总值。
- **几何**：`startangle=90`（12 点钟）；`counterclock=False`（顺时针）；`wedgeprops={'edgecolor':'white','linewidth':2}`。
- **标注**：`autopct='%1.1f%%'`，`pctdistance=0.7-0.85`；过长用引出线。
- **常见错误**：类别 >7、3D 饼图、非 100% 数据用饼图。

### 5.7 雷达图 / 极坐标图
- **配色**：多边形填充 alpha=0.15–0.25；轮廓线 linewidth 2.0；网格 #CCCCCC alpha 0.5。
- **几何**：3–8 维最佳；3–5 圈同心多边形；`projection='polar'`。
- **常见错误**：维度 >8、未标准化（不同量纲）、>4 个多边形重叠。

### 5.8 3D 图（曲面/散点/柱/等高线）
- **配色**：曲面 terrain/viridis/gist_earth（地形）、coolwarm/RdBu_r（科学）；3D 散点按 Z 值 viridis 渐变。
- **几何**：`elev=20-30°, azim=30-60°`；`plot_surface` rstride=cstride=5–10；`contour(z, offset=min_z)` 投影底面；`shade=True`。
- **标注**：轴标签含单位；colorbar 必备。
- **常见错误**：3D 柱图（透视扭曲）、视角遮挡、无 colorbar、网格过密。

### 5.9 地图（散点/分级/流向/热力）
- **配色**：底图浅灰 #F5F5F5 + 灰 #999 边界；散点 viridis 渐变；分级图 sequential + BoundaryNorm；流向弧线透明度映射量级。
- **几何**：投影 Plate Carrée / Mercator / Albers（中国）；指北针 + 比例尺必备。
- **常见错误**：无比例尺、**中国地图缺台湾省/南海九段线（政治正确性）**、colorbar 范围不匹配。

### 5.10 流程图与方法学框架图
- **配色**：节点背景淡色系（#FFF3E0 橙 / #E8F5E9 绿 / #E3F2FD 蓝 / #FCE4EC 粉 / #F3E5F5 紫）；节点边框深色系；箭头深灰 #333 linewidth 1.5–2.5。
- **几何**：圆角矩形 `boxstyle='round,pad=0.3-0.5'`；平行四边形输入输出；菱形判断；节点网格对齐；大区域虚线圆角矩形包围。
- **标注**：节点文字 ≤5 词 9–10 pt；分区标题背景色条；箭头标注 `import`/`convert`/`apply`。
- **常见错误**：箭头交叉、节点 >20、配色 >5 种、文字溢出。

```python
from matplotlib.patches import FancyBboxPatch, FancyArrowPatch
box = FancyBboxPatch((x, y), w, h, boxstyle='round,pad=0.3',
                      facecolor='#E3F2FD', edgecolor='#1565C0', linewidth=1.5)
arrow = FancyArrowPatch((x1, y1), (x2, y2), arrowstyle='->',
                         color='#333', linewidth=1.5, mutation_scale=15)
```

### 5.11 网络图 / 弦图 / 桑基图
- **配色**：节点按类别 Set1 / 按中心性 viridis；边 alpha 0.3–0.6；桑基左右节点离散色。
- **几何**：节点 `s=50-3000`（按度/中心性）；边宽 0.5–3.0（按权重）；布局 spring/circular/kamada_kawai/shell。
- **常见错误**：节点 >50、边 >5×节点数、节点重叠。

### 5.12 统计图（ROC / 森林 / 生存 / 火山 / 曼哈顿）

**ROC 曲线**：每条模型一条曲线不同颜色；y=x 参考灰虚线；图例含 AUC 降序；bootstrap 95% CI 阴影；不平衡数据同时画 PR 曲线。

**森林图**：左列研究名 + 中列点+95%CI 横线 + 右列 weight/OR(HR)；底部菱形 ◆ 合并效应量；x=1 无效应参考线；底部标注 I²、Q。

**生存曲线 (KM)**：阶梯线 step plot；删失点 tick `|`；底部 No. at risk 风险表；Log-rank p + HR(95%CI)。

**火山图**：x=log2(FC)，y=-log10(p)；显著上调红 / 下调蓝 / NS 灰；阈值线 p=0.05 + |FC|=1.5；关键基因 ≤10 个标签。

**曼哈顿图**：x=染色体位置，y=-log10(p)；染色体交替深浅；红线 genome-wide significance (p<5e-8)。

## 6. 统计标注与显著性规范

### 6.1 显著性符号

| 符号 | 含义 | p 值 |
|------|------|------|
| ns | not significant | p > 0.05 |
| \* | significant | p < 0.05 |
| \*\* | very significant | p < 0.01 |
| \*\*\* | highly significant | p < 0.001 |
| \*\*\*\* | extremely significant | p < 0.0001 |

### 6.2 检验方法标注（按场景选）
- 正态性：Shapiro-Wilk / Kolmogorov-Smirnov
- 方差齐性：Levene's / Bartlett's
- 两组比较：Student's t（配对/独立）/ Mann-Whitney U / Wilcoxon signed-rank
- 多组比较：One-way/Two-way ANOVA + post-hoc（Tukey/Bonferroni/Dunnett）/ Kruskal-Wallis + Dunn
- 相关性：Pearson（线性）/ Spearman（单调）/ Kendall（小样本）
- 生存分析：Log-rank / Cox
- 多重比较校正：Bonferroni / FDR (Benjamini-Hochberg) / Holm

### 6.3 效应量与置信区间
- r 值标 r 与 p；r² 反映解释方差。
- OR/HR 必须附 95% CI（如 `OR=2.3 (1.5-3.4)`）。
- Cohen's d：小 0.2 / 中 0.5 / 大 0.8。
- 回归模型必标 R² / Adjusted R²。

### 6.4 样本量与误差棒
- n=XX 必须出现在图注或图中。
- 误差棒类型明确：SD / SEM / 95% CI / IQR。
- 三组及以上用 ANOVA 而非多重 t-test。

## 8. 智能补图（v3.0 新增）

AI 完成美化后自动进入「智能补图」模式：扫描论文全文，识别「该有图但没有图」的空白区域，按论文内容生成流程图/示意图并插入。

### 8.1 触发条件（哪些章节该补图）

| 检测项 | 触发条件 | 补图类型 | 优先级 |
|--------|---------|---------|--------|
| 问题分析流程图缺失 | 问题分析/模型构建无流程图 | 整体方法学流程图 | ★★★★★ |
| 模型框架图缺失 | 模型建立仅文字无框架图 | 模型架构流程图 | ★★★★★ |
| 算法步骤图缺失 | 算法过程冗长无流程图 | 算法步骤流程图 | ★★★★ |
| 结果对比无图 | 结果有数值对比无图 | 柱状图/折线图 | ★★★★ |
| 灵敏度分析无图 | 灵敏度有表格无图 | 热力图/雷达图 | ★★★★ |
| 对比分析无图 | 多方案对比无图 | 对比柱状图/雷达图 | ★★★★ |
| 数据预处理无图 | 数据清洗无可视化 | 数据流程图 | ★★★ |
| 时间线/调度无图 | 时间序列仅文字 | 甘特图/时间线 | ★★★ |
| 空间分布无图 | 涉及地理数据无地图 | 散点/热力地图 | ★★★ |
| 指标体系无图 | 评价指标无层次结构 | 层次结构图/树图 | ★★★ |

**图文比阈值**：问题分析/模型建立 >800 字/图 → 补图；结果分析 >500 字/图；灵敏度 >400 字/图；前言 >1000 字/图（可选）。

### 8.2 补图不虚构 — 五条铁律
① 所有图表数据必须来源于论文原文的文字/表格/已有图，禁止编造数值。
② 原文仅定性描述无数值 → 生成定性对比图而非定量图。
③ 数据不完整 → 图注标注「数据来源：论文 §X.X」并注明估算部分。
④ 补充图风格（配色/字体/DPI/边距）与论文已有图表一致。
⑤ 每张补图有完整图题、图注、数据来源说明。

## 9. 常见错误与避坑（20 类）

| 错误 | 正确做法 |
|------|---------|
| 数据修改（改数值/趋势） | 严格保真，原图有错仅提示 |
| 类型转换（柱改饼） | 保留原类型，需改先与用户确认 |
| 3D 柱图 | 用 2D 替代 |
| 双 Y 轴滥用 | 最多 1 个 Y 轴，双 Y 轴需比例对应 |
| jet/rainbow 彩虹色 | 用 viridis/plasma/RdBu_r |
| 字号 <6 pt | 最小 7 pt，推荐 8–10 pt |
| minor grid 满天星 | 仅 major grid |
| 轴标签缺单位 | 必须含单位 |
| 图例缺失 | 图例完整、不遮挡 |
| colorbar 缺失 | 热力图/3D 必须 colorbar |
| 显著性缺失 | 星号 + p 值双标注 |
| Outlier 误判 | 用 1.5×IQR |
| 文字溢出节点 | 换行/缩写/缩字号 |
| 误用饼图 | 饼图仅用于占比 |
| 中国地图缺台湾/九段线 | 必须含台湾省 + 南海诸岛 + 九段线 |
| 时间序列格式混乱 | 统一 'YYYY-MM' |
| 拟合过度平滑 | 保留原始数据点 + 拟合线 |
| 误差棒缺失 | SD/SEM/95%CI 必含其一 |
| 雷达图维度过多 | ≤8 维，>8 改用平行坐标 |
| colorbar 范围不匹配 | 范围与数据对齐 |

## 10. 附录：matplotlib 终极模板

```python
import matplotlib.pyplot as plt
import numpy as np
from matplotlib import rcParams

# ============= 全局配置 =============
rcParams['font.family'] = 'Arial'
rcParams['font.size'] = 10
rcParams['axes.linewidth'] = 0.8
rcParams['axes.labelsize'] = 11
rcParams['axes.titlesize'] = 12
rcParams['xtick.labelsize'] = 9
rcParams['ytick.labelsize'] = 9
rcParams['legend.fontsize'] = 9
rcParams['figure.dpi'] = 100
rcParams['savefig.dpi'] = 300

def style_axes(ax):
    ax.spines['top'].set_visible(False)
    ax.spines['right'].set_visible(False)
    ax.spines['left'].set_color('#333333')
    ax.spines['bottom'].set_color('#333333')
    ax.tick_params(colors='#333333', direction='out', length=4)
    ax.grid(axis='y', linestyle='--', linewidth=0.5, color='#CCCCCC', alpha=0.5)
    ax.set_axisbelow(True)

# ============= 绘图 =============
fig, ax = plt.subplots(figsize=(8, 6))
x = np.arange(5); y = np.random.rand(5) * 10
ax.bar(x, y, color='#1F3A93', edgecolor='#333', linewidth=0.8, width=0.6)
ax.set_xticks(x); ax.set_xticklabels(['A', 'B', 'C', 'D', 'E'])
ax.set_xlabel('Category'); ax.set_ylabel('Value (unit)')
ax.set_title('My Publication-Quality Figure', fontweight='bold', pad=10)
style_axes(ax)
plt.tight_layout()
plt.savefig('figure.pdf', dpi=300, bbox_inches='tight')
```
