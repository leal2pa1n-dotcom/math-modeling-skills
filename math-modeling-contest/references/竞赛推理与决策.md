# 竞赛推理与决策（把 AI 从「论文生成器」变成「队友」）

> 核心命题：不要训练/使用一个「看到关键词就套模型」的数模 AI，而要一个「先识别问题结构，再考虑模型，最后怀疑自己的结果」的队友。
> 本文是 skill 之上的**操作系统**，不是多一个步骤，而是所有步骤都要经过的决策层。它与其他 reference 互补：`题型与方法论.md` 讲「每类题的完整方法链」，`模型选取指南.md` 讲「同类里选哪个 + 为什么」，本文讲「拿到陌生题时**怎么想、怎么选、怎么查、怎么怀疑、什么时候停**」。

## 一、决策优先的核心理念

面对陌生题目，正确的心智顺序（**不可颠倒**）：

1. 这个问题**到底是什么**？（结构、目标、约束、数据结构）
2. 有哪些**合理建模路径**？（候选，不只一条）
3. 哪个模型**最适合当前数据与约束**？（前提假设对上）
4. 我的结果**真的可靠吗**？（验证 + 敏感性 + 停止条件）

**反模式**：第一反应是「我会什么模型」→ 从自己的武器库里挑一个套上去。这会漏掉「这题根本不该用预测，而该用结构/机理模型」的判断。例子：预测城市人口——普通 AI 直接上 ARIMA/灰色/LSTM；队友型 Agent 会先问「样本多少？有无结构性变化？是否受出生/死亡/迁移驱动？数据量够不够 LSTM？」，最后可能说「**这题不该优先 ARIMA，该从人口结构模型（cohort-component）出发**」。

## 二、全流程决策链（22 步）

```
读题 → 识别题型 → 拆分子问题 → 提取变量 → 识别目标与约束
→ 搜索类似历史题 → 调用模型知识 → 提出 2~4 个候选方案
→ 比较方案 → 选择模型 → 找数据/清洗 → 建立模型 → 计算
→ 验证 → 敏感性分析 → 发现问题 → 必要时重建 → 组织论文
```

关键不是走完 22 步，而是**每一步都能停下来问一句**：

- 「我这一步的假设成立吗？」
- 「有没有更简单的方法得到同样的结论？」
- 「这个数可靠吗，还是我硬凑出来的？」

## 三、拆题四件套（第 0.5 步核心）

拆题不是复述题目，而是产出四件可交付物：

1. **子问题清单**：把大题拆成 2~5 个可独立建模的子问题（对应论文的各问）
2. **变量定义**：决策变量 / 状态变量 / 外生变量 / 参数，各标注数据来源
3. **目标与约束**：目标函数（最大化/最小化什么）、硬约束 vs 软约束
4. **数据结构画像**：样本量、时间维度、删失、不平衡、量纲、缺失

然后**强制生成 2~4 个候选方案**，每个候选一行：

```
候选名 | 模型族 | 适用条件 | 数据要求 | 优点 | 缺点 | 可解释性
```

## 四、选模决策：显式写「为什么选它，为什么不选另一个」

拉开差距的关键。不要只写「本文用 XGBoost」，要写决策过程：

> **题目**：预测城市用电量
> **候选**：ARIMA / Random Forest / XGBoost / LSTM
> **分析**：
> - ARIMA：+ 时序结构强、样本要求低；− 非线性能力有限
> - RF：+ 非线性、抗异常值；− 时间依赖建模弱
> - XGBoost：+ 非线性、特征交互；− 需特征工程
> - LSTM：+ 复杂时间依赖；− 数据量要求高、本科易过度建模
> **最终**：ARIMA（时间结构）+ XGBoost（非线性特征）
> **原因**：一个负责时序骨架，一个负责非线性残差，组合优于单模型。

**决策三问**（任何题先过一遍，详见 `模型选取指南.md`）：

1. 数据长什么样？（样本量 / 时间维度 / 删失 / 不平衡 / 量纲）
2. 题目要我输出什么？（排序 / 预测值 / 最优方案 / 标签 / 分组 / 机理关系）
3. 怎么评我做对没有？（准确率 / 召回 / 误差 / 稳健性 / 可解释性）

→ 三者对齐才选模型；对不齐优先换模型，而非硬调参。

**反直觉升级**（复用本 skill 核心原则）：
- 优化题先判类型（MILP/MINLP/MIQP），精确求解器（Gurobi/OR-Tools）求 baseline 再上 pymoo，证明「元启发式能否逼近最优」；
- 风险建模画**收益-风险 Pareto 前沿**，不只报「风险后利润下降」；
- 不均衡别报「99.7% 准确率」，看 Recall/PR-AUC/MCC/Calibration。

## 五、外部事实检索：数学推导与事实查询必须分开

Agent 比普通数模 AI 强的一点：**遇到外部事实，不知道就去搜，绝不编。**

判断流程：

```
这个量我可以自己推导吗？
 ├─ 能 → 推导，写清过程
 └─ 不能（人口/GDP/物理参数/官方统计/材料参数…）→ 必须检索
      → 搜索关键词
      → 权威来源（政府/官方统计/原始论文/原始数据库）
      → 第二来源交叉验证
      → 是否一致？
      → 记录出处 + 时间
      → 带证据进入模型
```

**铁律**：
- 未知事实**不得自行编造**。
- 无法确认时，明确写「**未验证**」。
- 引用带来源 + 时间（数据会随时间变化）。

**本地资料 vs 网络资料冲突**：不要自动选任何一边，先判断冲突类型——
- **时间差**？（本地 2024 年人口 1000 万 vs 网络 2025 年 1030 万 → 是增长，不是矛盾）
- **定义/口径不同**？（统计口径、数据版本不同）
- **真正冲突**？（本地 GDP 2.1 万亿 vs 官网 1.8 万亿 → 进入冲突检查，查口径，别随手选一个）

## 六、敏感性分析：默认反射，不是可选项

**只要模型依赖关键参数，就问一句「结果稳不稳」。**

方法：一次一变（OAT）/ 参数扫描 / 情景分析 / 蒙特卡洛敏感性 / 龙卷风图。

判稳不稳：

- 参数 +5% → 解 13.2→13.4；+10% → 13.7；−10% → 12.9 → **稳定，可写确定性结论**
- 参数 +5% → 13；+10% → 87 → **高度敏感，只能写条件性结论，并明说「此结论不稳」**

**哪些参数必须做敏感性**：题目给的假设参数、估计出来的系数、权重、阈值、折扣率、增长率、代价比……凡是「拍脑袋定的」都要扫。

## 七、停止条件：敢于说「当前结论不可靠」

Agent 不能永远建模。遇到以下情况，**明确停手并声明**，而不是继续生成看似完整的答案：

- 数据不足 / 证据不足
- 模型无法验证（无 baseline、无交叉验证、无外部校验）
- 模型极不稳定（敏感性测试剧烈跳动）
- 关键参数无法获得（又查不到）

正确输出是：「在当前数据与证据下，该结论不可靠，原因是 X；若需改进，需要 Y。」

## 八、失败案例 / 反例清单（建模纠错反射）

遇到以下任何一条，先停手去查，而不是继续：

| # | 失败模式 | 如何发现 | 如何修复 |
|---|---------|---------|---------|
| 1 | 强行套模型（20 样本上 50 特征 + XGBoost） | 样本量 vs 特征数/模型复杂度 | 降维 / 换简单模型 / 交叉验证 |
| 2 | 时间泄漏（`train_test_split(shuffle=True)` 切时序） | 训练用到了未来 | 按时间顺序切分 |
| 3 | 相关 ≠ 因果（Pearson r=0.92 就断因果） | 有无混淆变量 / 干预 | 只写「相关」，因果需额外设计 |
| 4 | 优化结果违反约束 | 逐约束代入验证 | 加罚项 / 修约束 |
| 5 | 幻觉引用（「某机构 2025 数据显示」网页不存在） | 逐条检索 | 换可查证来源或删 |
| 6 | 严重过拟合（训练 99% / 测试 60%） | 训练/测试差距 | 正则 / 降复杂度 / 增样本 |
| 7 | 严重共线性（VIF>10） | VIF / 相关矩阵 | 删共线变量 / 岭回归 |
| 8 | 异常值未处理 | 箱线图 / 分布 | 先看分布再定 |
| 9 | 单位 / 量纲错误 | 数量级核对 | 统一单位 |
| 10 | 归一化错误（按行归一化） | 检查 axis | 按列（特征）归一 |
| 11 | 指标方向搞反（正/负向） | 核对题目定义 | 正向化处理 |
| 12 | 模型假设不成立（非正态上参数检验） | 前提检验 | 换非参 / 变换 |
| 13 | 参数异常（负概率、负时间） | 范围检查 | 加约束 |
| 14 | 评价指标方向错误（越大越好 vs 越小越好） | 核对目标 | 反向处理 |
| 15 | 时间序列随机切分 | 同 #2 | 时序切分 |
| 16 | 数据缺失处理错误（直接删 / 均值填） | 缺失机制分析 | 按机制插补 |
| 17 | 论文—代码不一致（公式/参数/结果对不上） | 逐项比对 | 修正到可复现 |
| 18 | 组合模型无必要（简单方法已足够） | 对比 baseline | 砍掉过度建模 |

## 九、目标画像

最终这个 skill 驱动的 Agent 应该像：

> 「一个参加过多次数模、有丰富选模经验、知道什么时候该去搜资料、知道什么时候不该信自己的结果、能自己查错的本科队友」

而不是：

> 「一个背过很多模型名称的论文检索机器人」。
