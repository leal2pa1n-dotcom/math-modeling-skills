# math-modeling-contest

数学建模竞赛（**CUMCM 国赛 / 五一赛 / 美赛 MCM-ICM**）论文一站式产出与自查 skill。

把一道题从「原始题目 + 附件数据」变成一篇**可提交、经得起 AI 痕迹自查**的论文——核心是**决策优先**（先认结构再选模）：读题 → 拆题与选模决策 → 外部事实检索 → 数据预处理 → 分题型建模求解 → 论文写作 → AI 痕迹自查 → 提交合规核对 → LaTeX/PDF 产出。

## 它解决什么问题

数模竞赛最容易翻车的不是「不会建模」，而是这些隐蔽坑：

- 数据预处理漏做（重复检测、删失处理、VIF 共线性、异常值、指标方向）
- 选错模型（同类模型前提假设对不上、类别不平衡下报无意义的高准确率）
- AI 帮忙帮倒忙（编造文献/公式/数据、假设前后对不上）
- 格式不合规（正文超 30 页、图片型 PDF 无法查重、未匿名、AI 未标注）

本 skill 把获奖论文的「正确姿势」固化成可复用的工序，让 AI 按固定流程干活、你只做关键决策与验收。

## 安装

本 skill 只依赖标准 `SKILL.md`（YAML 头 `name` + `description`）+ `references/`，三个主流 Agent 都能加载。

### Claude Code

把整个目录复制到项目 `.claude/skills/` 或全局 `~/.claude/skills/` 下即可（目录名保持 `math-modeling-contest`）。

### Codex CLI

```bash
npx skills add <owner>/math-modeling-contest --agent codex --skill '*' --yes
```

（把 `<owner>/math-modeling-contest` 换成实际放这个 skill 的 GitHub 仓库路径。）

### DeepSeek Harness (DSH)

```bash
dsh plugin add <owner>/math-modeling-contest
```

## 使用

当用户给出数模竞赛题目（含附件数据）、要求做题/建模/写论文，或要求对已有论文做 AI 痕迹自查 / 备赛规划时，调用本 skill。

核心原则（务必遵守）：

0. **决策优先，先结构后模型**——先认「这题是什么结构/目标/数据」，生成 2~4 个候选再显式选模，别看到关键词就套模型；该搜的事实去搜不编，结果不稳就说不可靠。
1. **人主导，AI 执行，可追溯**——决策你来做，AI 只执行；配合 2026 国赛 AI 新规保留使用记录。
2. **先简单后复杂**——简单方法先做基线，复杂方法做对比。
3. **永远验证，不盲信**——AI 给的文献/公式/数据都要独立验证。
4. **获奖优先级**——数学结构 > 可解释 > 求解稳定 > 对比实验 > 图表 > 算法数量。
