# 数模竞赛 skill

把一道数学建模竞赛题从「原始题目 + 附件数据」变成一篇可提交的、经得起 AI 痕迹自查的论文。

## 何时使用

- 用户给出国赛/五一赛/美赛的题目（含附件数据），要求做题、建模、写论文
- 用户要求对一篇已有的数模论文做 AI 痕迹自查 / 质量评审
- 用户要求把建模结果工程化产出（Markdown → LaTeX → PDF → docx）
- 用户要求做备赛规划（N 天冲刺计划、学习路径、时间管理）
- 用户问「用 Codex / DeepSeek Harness / Claude Code 这类 Agent + skills 怎么做数模」「模型怎么选」「零基础怎么速成」

## 核心原则（蒸馏自真实获奖复盘）

0. **决策优先，先结构后模型**：面对陌生题，第一反应不是「我会什么模型」，而是「这题到底是什么结构、目标是什么、数据长什么样、有哪些合理路径」。拆题 → 生成 2~4 个候选 → 显式比较 → 选模（写理由）→ 才谈建模。详见 `references/竞赛推理与决策.md`。

1. **共同核心是「逐层转换」这条链，不是用了多少高级算法**：`数据理解 → 机制/统计分析 → 数学模型 → 算法求解 → 稳健性验证 → 决策输出`。典型四问结构：问题一认识变量 → 问题二处理不确定性 → 问题三处理变量关系 → 问题四做决策，结尾用敏感性分析证明可靠。
2. **数模不是堆模型，而是把「数据结构 + 题目目标 + 评价逻辑」三者对齐。** 真正拉开差距的不是模型多复杂，而是有没有读懂题目藏在数据里的坑。
3. **AI 是工具，不是队友。你负责想，它负责干。** 每个环节都是「你定方向 → AI 执行 → 你审核」，永远不能把决策权交给 AI。
4. **永远验证，不盲信。** AI 的每条文献去数据库搜、每个公式手算小例子验证、每个数据追溯来源；AI 推荐的每个方法都要核对前提假设与数据是否匹配。
5. **获奖优先级（比赛导向）**：数学结构漂亮 > 可解释 > 求解稳定 > 对比实验 > 图表 > 用了多少高级算法（最后才是算法堆砌）。
6. **敏感性是反射，敢于说「不可靠」**：只要模型依赖关键参数就问「结果稳不稳」；数据/证据不足、无法验证时，明确写「当前结论不可靠」，不硬凑完整答案。详见 `references/竞赛推理与决策.md`。

**反直觉的升级点（比论文做得更好的关键）**：
- 优化题不要一上来就元启发式——先判断问题类型（MILP/MINLP/MIQP），用精确求解器（Gurobi/OR-Tools）求 baseline，再上 pymoo，证明「元启发式能否逼近最优」。
- 风险建模要画**收益-风险 Pareto 前沿**，不只报「风险后利润下降」。
- 类别不平衡下「99.7% 准确率」无意义，要看 Recall/PR-AUC/MCC/Calibration。

## 完整工作流

### 第 0 步：读题与问题分流（6 维）

把题目原文完整精读，提取关键词、隐含条件、约束、数据范围、输出要求，然后判断题型并分流到对应路径：

| 维度 | 典型特征 | 首选方法族 | 参考案例 |
|------|---------|-----------|---------|
| **评价类** | 多指标排序/综合打分 | 熵权法、AHP、CRITIC、TOPSIS、灰色关联 | 城市交通拥堵评价 |
| **预测类** | 时间序列/回归外推 | XGBoost、特征工程(lag/滚动/时间编码)、ARIMA、LSTM | 26C 光伏功率预测 |
| **优化类** | 约束下求最优方案 | 线性/整数规划、智能算法(DE/GA/PSO)、博弈论 | C038 农作物种植规划 |
| **分类/判别** | 二分类/多分类标签 | 逻辑回归、代价敏感、SVM、集成 | 25C NIPT 女胎异常筛查 |
| **生存/删失** | 事件时间+删失样本 | Kaplan-Meier、AFT、Cox | 25C NIPT 达标时间 |
| **机理/物理** | 有明确物理/化学规律 | 微分方程、机理建模、参数辨识 | 光伏理论功率模型 |

读题阶段可让 AI 帮忙，但**必须把题目原文完整粘贴**（不要自己概括，会漏关键信息），并追加一问「这道题最容易踩的坑是什么」。

### 第 0.5 步：拆题与选模决策（决策优先，非可选）

先把题目拆成**四件套**（子问题清单 / 变量定义 / 目标与约束 / 数据结构画像），再**强制生成 2~4 个候选方案并显式比较**，写出「为什么选它、为什么不选另一个」——这是拉开差距的关键，也是「队友」与「论文生成器」的分界。

同时**把「数学推导」和「外部事实查询」分开**：能自己推导的写清过程；人口/GDP/物理参数等外部事实必须检索、多源交叉验证、记录出处与时间，查不到就写「未验证」，绝不编。

> 完整决策链、候选比较模板、事实检索流程、敏感性反射、停止条件、18 条失败案例反例清单 → 见 `references/竞赛推理与决策.md`。

### 第 1 步：数据预处理（先于建模，最易被忽视）

按「数据结构 → 题目目标 → 评价逻辑」的顺序先理清数据：

- **重复检测/重复测量**：同一主体多次记录不能当独立样本，需聚合为主体级数据（如孕妇级），否则标准误和显著性失真。
- **删失数据**：只有观测到部分信息（如「始终未达标」），要作左删失/右删失处理，不能简单丢弃或当完整数据。
- **共线性诊断**：多因素强相关时先算 VIF（方差膨胀因子），剔除结构性共线变量（如 BMI 与身高体重由定义相关），保留独立信息变量。
- **异常值/缺失值**：先看分布再决定处理方式，不能直接均值/删除。
- **指标方向**：正向/负向指标标准化方向不能搞反；标准化按行还是按列（axis）要核对。
- **样本不均衡**：阳性样本比例低时不要只盯 AUC/准确率，要关注召回率、漏判/误判代价。

### 第 2 步：建模与求解（分题型）

参照 `references/题型与方法论.md`。通用要点：

- 每个模型先给「问题分析」（数学本质是什么），再给「模型建立」（符号 + 公式 + 假设），再给「模型求解」（算法/代码），再给「结果 + 检验」。
- **简单方法先做基线**，复杂方法做对比；若简单方法结果接近复杂方法，说明问题不复杂，不要过度建模。
- 模型链条要清晰可追溯，例如：`重复记录 → 主体级事件时间 → 生存回归 → 分组 → 目标时点 → 敏感性分析`。
- **敏感性反射**：模型依赖关键参数就做 OAT/扫描/情景敏感性，判「稳→确定性结论 / 不稳→条件性结论」；**停止条件**：数据/证据不足、无法验证、参数查不到时，明确写「当前结论不可靠」而非硬凑。

### 第 3 步：论文写作（结构规范）

参照 `references/论文结构规范.md`（结构）、`references/国奖论文优化提示词.md`（九大模块 + 硬指标清单，冲国奖）、`references/顶刊图表美化提示词.md`（图表视觉规范）。通用结构：

```
摘要 + 关键词 → 一、问题重述 → 二、问题分析 → 三、模型假设
→ 四、符号说明 → 五~八、各问「模型建立与求解」 → 灵敏度分析
→ 模型评价与推广 → 参考文献 → 附录(代码)
```

> 写作时同步遵守提交规范：正文（不含附录）≤30 页、不要目录、全文匿名（不出现姓名/学校/赛区）。详见 `references/竞赛规则与提交规范.md`。

### 第 4 步：AI 痕迹自查（交稿前必做）

参照 `references/AI辅助与自查.md`。AI 写论文的高频致命错误——**假设前后对不上、自编文献和结论、数据来源捏造**——是评委一眼看穿的地方。交稿前按 26 维自查表逐项检查（假设一致性、文献真实性、数据来源、公式正确性、代码结果可复现），全部合格才可提交。

### 第 5 步：工程化产出

一站式链路：`Markdown 草稿 → LaTeX 正文 → 编译 PDF → 导出 docx`。

- 用 LaTeX（`ctex` + `amsmath` + `booktabs` + `listings`）排版，`xelatex` 编译
- VSCode + LaTeX Workshop：`ctrl+Shift+p` → `LaTeX Workshop: View LaTeX PDF`
- 公式用 `$$...$$`，表格用 `booktabs`，代码用 `lstlisting`，图表用 `tikz`/`matplotlib` 矢量图

### 第 6 步：提交合规检查（交稿前必做）

参照 `references/竞赛规则与提交规范.md`。这是**硬性规则**，违反直接取消评奖，与建模质量无关：

- 正文（不含附录）≤30 页、不要目录；PDF **非图片型**（可复制文字、可查重）、未禁拷贝
- 电子版 PDF/Word ≤20MB 不压缩；支撑材料 ZIP/RAR ≤20MB
- 全文匿名（无姓名/学校/赛区）
- AI 工具**规范标注**（或声明「本参赛队未使用任何AI工具」）

## 双模式

- **全自动模式**：从题目到 PDF 一条龙，适合明确题型、数据干净的情况
- **人工把关模式**：每个关键节点（选型、建模、求解、写作）停下来让用户确认，适合题型模糊、数据「脏」、需要取舍的情况

## 交付物

- 建模求解代码（带详细注释 + 打印中间结果，方便审查）
- 论文（`.md` 草稿 + `.tex` + 编译后的 `.pdf`）
- 结果表（`result*.xlsx` / `result*.csv`）
- AI 自查结果表（可选，若有）
